I built this digital magazine, or zine, in collaboration with the March Caprice team. March Caprice is an annual online celebration that brings together hundreds of Kingdom Heart fans to celebrate the series.

The March Caprice team reached out because they wanted a way to package all of the information about the event into a format that matched the theme of the early 2000s. 
The idea was to make something inspired by old Nintendo Power magazines, but available digitally and with a global audience in mind. 

With a bit of cleverness, I built an embeddable site for the zine instead of using something that compiles to a PDF or series of images in a booklet format. Instead of a static asset, the team really wanted users to be able to search through the document, have a clickable table of contents, and most importantly, view event schedules in their local timezone.

This project showed me that I often take some of the fundamental value of hypertext and web development for granted. Nowadays we have really great optical image recognition that blurs the boundary between images and documents. That's awesome, but it's equally awesome to me that by taking a slightly different path to building a zine, I enabled some really cool usability and got a bunch of accessibility features built into the browser for free.

When you build something for a community you care about, you should build it in way that makes it accessible and inclusive. Being able to do that with this project was very rewarding, and I'm grateful I was asked to work on it.
