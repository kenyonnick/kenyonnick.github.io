## [Check it out](https://www.clipgarden.tv)

## Purpose
I made this website so that me and my friends on Twitch had a place to easily share our clips and keep up with what's happening on each other's streams. I also added some tools to make some things easier, like automatic clip reels that you can put in an OBS browser source, saving you the time of editing and rendering out clip reels.

## Tech
### Supabase
I wanted to try Supabase and see how easy it made getting a project up and running. I used it for my database and auth, with the Twitch auth provider.

### NextJS
I typically use NextJS for my web projects because it's what I know and I can iterate quickly with it. Supabase and NextJS have good docs and support for working together, which made me happy.
